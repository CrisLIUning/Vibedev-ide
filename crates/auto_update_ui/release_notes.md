# VibeDev 更新日志

## 1.7.7

- **AgentApp 独立窗口**:全新的 Agent 工作台——左侧历史会话、中间对话区、右侧工作台(文件列表 / 文件 / 更改 / 执行 / 计划 / 终端可堆叠折叠);IDE 右上角一键打开 AgentApp,AgentApp 内一键返回 IDE,并可设置默认启动界面(AgentApp 或 IDE)。
- **多子智能体**:对话中并行派发的子智能体以扇出卡片直接呈现(替代原始工具折叠),右侧"执行"面板实时展示每个子智能体的进度与工具调用;全部完成后主智能体自动续轮汇总结果,无需手动催促。
- **修复**:右侧"文件"模块——点击文件树不再出现"不自动弹出 / 面板两种形态"的问题。
- **修复**:账户面板在后端已就绪时误报"后端未就绪"(残留握手自愈 + 退出时优雅清理)。
- **后端 2.6.21**:模型身份去品牌加固;修复上游不稳定时工具重复执行 / 结果串台;子智能体结构化进度与回复上报。

## 1.7.6

- **彻底 VibeDev 化**:项目设置目录改用 `.vibedev/`(`/.vibedev/settings.json`),同时继续读取既有 `.zed/` 配置(与使用 Zed 的协作者共享的项目无缝兼容)。
- **深链协议更名**:`zed://` 链接协议改为 `vibedev://`(设置 / Agent / 仓库克隆 / 技能分享等)。
- **品牌清理**:Finder 文件类型("种类")、macOS 系统权限弹窗、Windows 进程名等系统层的 Zed 字样改为 VibeDev。
- **修复**:Windows 安装版命令行(SSH 远程 / git 密码认证)因内部 CLI 路径名错误而失效的问题。

## 1.7.5

- **修复**:Agent 模式选择器(默认 / 接受编辑 / 计划模式 / 自动 / 绕过权限 / 不再询问)的名称与描述现已正确中文显示(此前该下拉改由新组件渲染,运行时翻译未生效)。
- **优化**:命令行 `vibedev --help` 文案品牌化(去除 Zed 字样)。

## 1.7.4
