# VibeDev 更新日志

## 1.7.6

- **彻底 VibeDev 化**:项目设置目录改用 `.vibedev/`(`/.vibedev/settings.json`),同时继续读取既有 `.zed/` 配置(与使用 Zed 的协作者共享的项目无缝兼容)。
- **深链协议更名**:`zed://` 链接协议改为 `vibedev://`(设置 / Agent / 仓库克隆 / 技能分享等)。
- **品牌清理**:Finder 文件类型("种类")、macOS 系统权限弹窗、Windows 进程名等系统层的 Zed 字样改为 VibeDev。
- **修复**:Windows 安装版命令行(SSH 远程 / git 密码认证)因内部 CLI 路径名错误而失效的问题。

## 1.7.5

- **修复**:Agent 模式选择器(默认 / 接受编辑 / 计划模式 / 自动 / 绕过权限 / 不再询问)的名称与描述现已正确中文显示(此前该下拉改由新组件渲染,运行时翻译未生效)。
- **优化**:命令行 `vibedev --help` 文案品牌化(去除 Zed 字样)。

## 1.7.4

- **中文化**:命令面板(Ctrl+Shift+P)的**全部命令**现已中文显示(补全了 1.7.3 遗漏的编辑器 / Vim / 各面板等近千条命令)。
- **修复**:Windows 自动更新——下载与安装移到后台,不再卡住界面约 14 秒;修复安装时 "os error 5"(交换文件前先结束后台 agent 进程,释放文件占用)。

## 1.7.3

- **中文化**:命令面板与 Agent 模式选择器(默认 / 接受编辑 / 计划模式 / 自动 / 绕过权限 / 不再询问)开始中文显示。
- **更新体验**:"查看更新"现在显示 VibeDev 版本号与本次更新内容(不再是空白的 Zed 页面)。
- **修复**:macOS 自动更新安装失败(磁盘镜像卷名匹配问题)。
- **优化**:模型选择器悬浮标签中文化;网络标识(User-Agent)与 CLI 版本号去除 Zed 残留。

## 1.7.2

- **修复**:扩展市场"加载扩展失败"。
- **优化**:隐藏 macOS 上误装 Zed CLI 的入口;遥测来源标识统一为 vibedev。

## 1.7.1

- 修复 1.7.0 误发英文版的问题,重新本地化为中文。
